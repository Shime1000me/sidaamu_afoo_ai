Project Overview

This project presents the first open-source, multi-modal AI ecosystem for Sidaamu Afoo, a Cushitic language spoken by approximately 10 million people in Ethiopia. The system includes a custom BPE tokenizer, a compressed translation model (NLLB-200), automatic speech recognition (ASR), and text-to-speech (TTS), all deployed on free-tier infrastructure.

155,114 Training Lines
8,000 Custom BPE Vocab
600 MB Compressed Model Size
4 Deployed Tools

Domain Bias Evaluation

We evaluated the CTranslate2 INT8 translation model on two distinct native test sets to measure domain performance.

Test Set Size BLEU chrF++
Formal / Biblical 26 sentences 16.13 58.55
Conversational / Everyday 300 sentences 2.43 23.84

Finding: The large performance drop on conversational text indicates a significant domain bias in the original Anley-Dev LoRA training data. This motivates our Human-in-the-Loop data collection pipeline.
